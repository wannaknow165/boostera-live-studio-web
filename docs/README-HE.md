# BOOSTERA Studio ואפליקציית המובייל

מאגר אחד עם קוד שני הפרויקטים שנבנו בלילה שבין 11 ל־12 בנובמבר 2026.

## פאנל Studio

קוד הפאנל נמצא בשורש המאגר. הפעילו `START.cmd` לפתיחת הפאנל בכתובת http://127.0.0.1:47831/ . נדרש TikTok LIVE Studio עם הגשר המקומי ופאנל Co-host פתוח. הוראות החיבור נמצאות ב־[STUDIO.md](STUDIO.md).

הפאנל מציג רשימות יוצרים והזמנות וכולל שליחת הזמנת Co-host לאחר אישור. אישור הזמנות נכנסות והתחלת באטל עדיין נעשים ב־Studio המקורי.

## אפליקציית דפדפן למצלמה ואפקטים

התיקייה `server-integration/wanna-studio-server` כוללת את שרת האפקטים ואת WANNA FX Mobile. לאחר התקנת התלויות והכנת הגדרות מקומיות לפי ה־README הראשי, מפעילים `start-mobile.cmd`.

- מצלמה ואפקטים: http://127.0.0.1:8801/mobile/
- ניהול לקוחות ואוטומציות: http://127.0.0.1:8801/mobile/manage
- תצוגת פלט: http://127.0.0.1:8801/mobile/viewer

האפליקציה כוללת קוד למצלמה, מיקרופון, מעקב פנים וגוף, אפקטים, קליפי קרב, תומכים ואוטומציות. שליחת הזמנות והפעלת באטל אינן ממומשות בה. יצירת וידאו חדש דרך ספק AI עשויה להיות בתשלום ודורשת הגדרה מקומית.

## מה נשאר מקומי

קוד האפליקציות והתיעוד נמצאים במאגר הציבורי. מפתחות, סיסמאות, נתוני לקוחות, תמונות אישיות, הקלטות וחומרי המדיה המקומיים אינם מפורסמים. הם נשארים בפרויקטים המקוריים. עותק חדש של המאגר דורש הגדרות ושחזור מדיה כדי להגיע לאותה ספרייה שבמחשב המקורי.

המאגר הציבורי הוא מאגר קוד. הוא אינו אתר חי ואינו אישור שבאטל אמיתי או שידור ציבורי נבדקו.

## בדיקת עצמאות מהסטודיו

מסלול מצלמה → שרת מקומי → RTMP נבדק עם וידאו וקול ללא LIVE Studio. פתיחת חדר LIVE בחשבון, הזמנת שותף והפעלת באטל עדיין אינן ממומשות באפליקציית המובייל. ללא יעד ומפתח RTMP פעילים אין שידור חיצוני. בדיקה ציבורית ב־TikTok עדיין לא הושלמה. פירוט הבדיקות והתיקונים נמצא ב־[דוח הבדיקה](STANDALONE-AUDIT.md).
