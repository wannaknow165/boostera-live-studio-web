# BOOSTERA LIVE Web 0.2.0

חדר בקרה בדפדפן שמציג את הנתונים האמיתיים של TikTok LIVE Studio במחשב שלך.

## פתיחה
לחיצה כפולה על START.cmd, או:
    node server.mjs --open

הפאנל נמצא בכתובת http://127.0.0.1:47831
נדרש Node.js 20 ומעלה. אין התקנת npm ואין מפתח API.

## חיבור לסטודיו
פתח את LIVE Studio עם הגשר המקומי כשהתוכנה סגורה. הנתיב שנבדק:
    Start-Process "C:\Program Files\TikTok LIVE Studio\1.39.6\TikTok LIVE Studio.exe" -ArgumentList "--devtoolsMcp=1","--remote-debugging-port=9222","--remote-debugging-address=127.0.0.1"

אל תפעיל מחדש את הסטודיו בזמן שידור. הפאנל אינו מתחיל או מסיים שידור.
פתח Co-host ואת Friends או Suggested creators כדי לטעון את הרשימות.

## קיים בגרסה זו
- מצב החיבור, הלייב, פאנל Co-host ורכיב הבאטל.
- רשימות אמיתיות שכבר נטענו בסטודיו, כולל שמות כשסופקו.
- חיפוש מקומי וסינון לפי מקור הרשימה.
- משתתפים מחוברים, הזמנות ממתינות, תוצאות ושגיאות אמיתיות.
- יומן שינויים, התאוששות מניתוק והסרת נתונים ישנים.
- כפתור מעבר לחלון LIVE Studio.
- שליחת הזמנת Co-host אחרי בחירת יוצר ואישור מפורש בפאנל. השליחה מפעילה את הכפתור המקורי של אותו יוצר בסטודיו.
- מניעת שליחה כפולה, בדיקת סשן מחודשת והפרדה בין בקשה שנקלטה, המתנה, דחייה ותוצאה לא ידועה.
- פקדי Match מקוריים: בחירת מצב, המשך להגדרה, שליחת הזמנת באטל, קבלה, דחייה וביטול הזמנה ממתינה. רק פקדים שנטענו וזמינים בסטודיו מוצגים בפאנל.

## עבודה ברקע
המחבר קורא את המצב ומפעיל פקדים דרך החיבור המקומי, בלי להזיז עכבר, להקליד או להעביר מיקוד לחלון Studio. אפשר לעבוד בחלונות אחרים כש־Studio פתוח מאחוריהם. חלון ממוזער או מסמך מוסתר אינו ניתן להפעלה דרך המחבר. כפתור המעבר ל־Studio הוא פעולה ידנית נפרדת שמפעילה את החלון.

ב־12 בנובמבר 2026 אומתה קריאת מצב מול Studio המקומי כש־document.hasFocus() היה false. בעת הבדיקה לא היה חדר LIVE פעיל; לא נשלחה ולא אושרה הזמנת באטל אמיתית. בדיקות הדפדפן משתמשות בנתונים מדומים.

## מגבלות מפורשות
שליחת הזמנת Co-host נתמכת כשהפאנל המקורי פתוח והיוצר זמין ברשימת Friends או Suggested creators.
המחבר מפעיל את כפתור ההזמנה המקורי המזוהה לפי UID דרך ממשק הניפוי המקומי שהפעלת. הוא אינו משנה קובצי TikTok, מחליף זהות של קורא API או עוקף הרשאות הזמנה.
אישור ודחיית הזמנות Co-host, התאמה אוטומטית ופתיחת פאנל Match עדיין מתבצעים בתוכנה המקורית. פקדי הזמנת באטל מופעלים מהדפדפן כשהפאנל המתאים פתוח. באטל אמיתי מול יוצר נוסף טרם אומת.
הזמנה שלא נקלטה בוודאות מסומנת כמצב לא ידוע. יש לבדוק בסטודיו לפני ניסיון נוסף.
תמונת וידאו, קול, ניקוד וטיימר אינם כלולים.
מצב pending נשאר המתנה גם אם שדה התצוגה ONGOING מופיע לרגע.
הסטודיו יכול להחזיר רשימות חלקיות; הפאנל מציג הודעה כשזוהתה קטיעה.

השרת מאזין רק ב-127.0.0.1. אין גישת רשת ציבורית, העברת טוקנים או שינוי בקובצי TikTok.
האתר המתארח מציע פתיחה מקומית והורדת המחבר. הוא אינו מציג נתונים מהמחשב מרחוק.
גישה מטלפון או ממחשב אחר תדרוש ממסר מאומת נפרד.

## בדיקות
    npm test

    python test/battle-controls-browser.py

הבדיקות מכסות את פרוטוקול TCP, תגובות מפוצלות, זיהוי בקשות,
סינון מידע, הפרדת סשנים, ניתוקים והגנת API מקומית.
הבדיקות משתמשות ביוצרים ובכפתורים מדומים ואינן שולחות הזמנות אמיתיות או משנות את השידור. בדיקת הכנה מול הסטודיו החי מזהה כפתור בלבד; בדיקת השליחה האמיתית מתבצעת על ידי בחירת היוצר ואישור שליחה בפאנל.
